# Конфигурация

## Параметры

| Параметр | CLI флаг | Переменная окружения | Обязательный | По умолчанию |
|----------|----------|---------------------|--------------|--------------|
| URL Redmine | `--redmine-url` | `REDMINE_URL` | Да | — |
| API ключ | `--redmine-api-key` | `REDMINE_API_KEY` | Да | — |

## Источники конфигурации (порядок приоритета)

1. **CLI-аргументы** — наивысший приоритет
2. **Переменные окружения** — если CLI не указаны
3. **`.env` файл** — загружается автоматически при вызове `Config::parse()`

## API-ключ Redmine

API-ключ можно получить в Redmine:
- Войдите в Redmine
- Откройте "Моя учетная запись" (My account)
- Вкладка "API"
- Ключ отображается в поле "API-ключ доступа"

## Безопасность

- API-ключ никогда не выводится в логах (Debug-формат показывает `***REDACTED***`)
- Храните ключ в `.env` файле, который добавлен в `.gitignore`
- Не передавайте ключ через CLI в многопользовательских системах

## Типы конфигурации

```rust
#[derive(Clone, Parser)]
pub struct Config {
    pub redmine_url: String,      // Redmine instance URL
    pub redmine_api_key: String,  // Redmine API key
}
```
